# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Одностраничная презентация «Нейросети и агенты: основы» на чистых HTML, CSS и JS: без сборки, зависимостей, линтера и тестов.

## Запуск

Открыть `index.html` в браузере — сервер не нужен. Скрипты подключены обычными `<script>` и связаны через глобальную `window.presentation`; на ES-модули не переводить: по `file://` модули не загружаются.

## Где что править

- Содержимое — разделы, блоки, тексты — только в `content/presentation.js`, в виде данных. Меню, обложку, оглавление и номера разделов страница строит сама: HTML и движок ради текста не трогать.
- Схема данных (поля разделов, типы блоков и их поля) описана в шапке `content/presentation.js`. Новое поле или тип блока — тем же изменением дописать туда.
- Новый тип блока: функция отрисовки в `assets/render.js` и запись в `BLOCK_RENDERERS`, раздел `/* ---------- <тип>: … ---------- */` в `assets/styles.css`, строка в шапке `content/presentation.js`.
- Иконки — ключи `ICON_PATHS` в `assets/render.js`: контур в сетке 24×24, заливка не рисуется (`.icon` — `fill: none`, `stroke: currentColor`).
- `basis.md` — план тем презентации.

## Тексты

Весь текст из данных экранируется: HTML в содержимом не работает. Разметка внутри текста — только `**выделение**` и `` `код` ``, и не во всех полях (список — в шапке `content/presentation.js`).

## Стили

- Тема одна, тёмная. Цвета — только переменные `--color-…` из `:root`, литералов цвета в правилах нет.
- Раскладка блока подстраивается под ширину самого блока через `@container` (у `.block` задан `container-type`), а не под экран: блок в полширины узок и на широком мониторе. `@media (max-width: 900px)` — только для каркаса страницы, меню и сетки блоков.
- Состояния — классы `is-accent`, `is-muted`, `is-spotlight`, `is-warning`; в данных им соответствуют булевы поля `isAccent`, `isMuted`, `isSpotlight`, `isWarning`.
